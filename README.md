# TelegramReader-FA

تلگرام‌خوان فارسی یک کلاینت سبک اندروید برای خواندن کانال‌های عمومی تلگرام با رابط راست‌به‌چپ است.

## نسخه 0.4.0

- رابط کامل فارسی و RTL
- دو بخش مستقل «اخبار» و «کافی‌نت» با فهرست کانال جدا
- چینش RTL و تراز Justify برای متن‌های طولانی (شبیه Justify در Word)
- فونت Vazirmatn در رابط و متن پست‌ها
- نمایشگر اختصاصی PDF مبتنی بر Pdfium با زوم و اسکرول روان
- بافر شروع ویدئو بهینه‌شده برای آغاز پخش سریع‌تر
- دو حالت تایپوگرافی سازگار با حروف فارسی
- افزودن کانال با `@username` یا لینک `t.me`
- خواندن مستقیم پست‌های عمومی از Telegram Web
- نمایش چندرسانه‌ای عکس و استیکر
- پخش ویدئو و GIF ویدیویی با Media3 / ExoPlayer
- نمایش تمام‌صفحه عکس
- تشخیص فایل‌های پست
- دانلود و نمایش PDF داخل برنامه با نمایشگر Pdfium
- نمایش متن قالب‌بندی‌شده و لینک‌ها
- صفحه‌بندی پست‌های قدیمی‌تر
- پراکسی HTTP / SOCKS
- کش HTTP و اسناد
- حالت روشن و تیره
- GitHub Actions برای ساخت APK

## درباره پیاده‌سازی

این پروژه به‌صورت مستقل و clean-room پیاده‌سازی می‌شود. هدف، رسیدن به رفتار و امکانات یک Telegram Reader حرفه‌ای است، بدون کپی‌کردن کد منبع پروژه‌های فاقد مجوز بازتوزیع مشخص.

> پروژه در حال توسعه است و ساختار HTML عمومی تلگرام ممکن است در آینده تغییر کند.
