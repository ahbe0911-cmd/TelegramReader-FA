# TelegramReader-FA

یک خوانشگر فارسی و راست‌به‌چپ برای کانال‌های عمومی تلگرام در اندروید.

## نسخه اولیه
- رابط فارسی و RTL
- افزودن کانال با @username یا لینک t.me
- دریافت پست‌های کانال عمومی از Telegram Web
- نمایش متن و تصویر
- ذخیره فهرست کانال‌ها روی دستگاه
- تنظیم پراکسی HTTP / SOCKS
- حالت روشن و تیره
- GitHub Actions برای ساخت APK

> این پروژه مستقل پیاده‌سازی می‌شود و کد پروژه‌های دیگر عیناً کپی نمی‌شود.
